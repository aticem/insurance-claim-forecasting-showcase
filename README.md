# Insurance Claim Cost Forecasting

> 🔒 **Showcase** — the source code is private. Walkthrough available on request via [LinkedIn](https://www.linkedin.com/in/acsamiloglu/).

Predicts the final cost of an insurance claim from the information recorded when it is first reported, so pricing decisions can be made earlier.

## Features
- Feature engineering on first-notification data
- LightGBM and Random Forest models compared

## Tech stack
Python · LightGBM · scikit-learn · Jupyter
